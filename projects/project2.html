Do We Still Have

Een slimme voorraad‑tracker voor thuis

Concept

Do We Still Have is een eenvoudige, slimme tool om bij te houden wat je nog in huis hebt. Geen dubbele boodschappen meer, geen vergeten producten achterin de kast — alles overzichtelijk op één plek.

Wireframe (eerste schets)

+--------------------------------------+
|            INVENTORY LIST            |
+--------------------------------------+
|  [ ] Pasta           2x              |
|  [ ] Tomaten         4x              |
|  [ ] Rijst           1x              |
|  [ ] Ui              3x              |
+--------------------------------------+
|        + Add new item                |
+--------------------------------------+

Belangrijkste functies

  • Voorraad bijhouden per categorie
  • Automatische waarschuwingen bij lage voorraad
  • Snel items toevoegen met één klik
  • Overzichtelijke lijst voor boodschappen
